04 / CLAIM BOUNDARY

What can be recovered?

The experiment distinguishes a measurable operator from the coordinates used to realize it.

01

An operator, not a neuron map

We construct a context-dependent response matrix H(c) = V G(c) Kᵀ. This resembles query–key–value factorization, but it is a signed linear response—there is no softmax, spike model, or learning here.

02

Interventions beat passive viewing

Two circuits agree when c = 0. The active observer chooses the context and input port with the largest predicted response disagreement. Only pulses at informative contexts can identify the specimen.

03

Some insides are unidentifiable

Under any invertible latent basis change R, set V′ = VR, K′ = KR⁻ᵀ and G′ = R⁻¹GR. The observable H(c) stays exactly the same. No amount of repetition distinguishes those coordinates.

OUR EXPERIMENTAL CONTRACTChoose a probe that changes the answer—otherwise report not identifiable.

What this demonstrates

An experimentally controlled synthetic inverse problem, a Bayesian two-hypothesis observer, and a mathematical impossibility case. Deterministic seed, Gaussian noise, and known candidate models make the outcomes reproducible.

What it does not demonstrate

Not actual EEG, not a recovered biological QKV circuit, not a new theorem, and not blind neural source separation. Its aim is to calibrate an observer before applying inverse models to real recordings or detailed compartment simulations.

Built from questions raised by BrainLoops, HeadAsResonator, LensLuotainTarget, Operaattori and TransientWaveCompiler. The mechanisms here are self-contained toy equations, not imported biological results.
